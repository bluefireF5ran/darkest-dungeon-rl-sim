# The engine + Gym env. This is all `python -m pytest tests/` needs.
#
# The upper bound on gymnasium is not decoration. `gymnasium>=1.0` with no
# ceiling is how `train.py --expedition` and the fixed mode came to be broken
# for an unknown length of time: gymnasium removed `Wrapper.__getattr__`, so
# the ActionMasker callable stopped reaching `action_masks` through a
# `TimeLimit`, and only `--full-expedition` (the one TimeLimit-exempt mode)
# kept working. Nothing failed loudly. See env/gym_env.py::mask_fn and
# tests/test_train_wiring.py, which now pins all three modes.
gymnasium>=1.0,<2
numpy>=2.0

# Reading the game binary (`tools/pe_anchors.py`, DECOMP.md). Optional and not
# imported anywhere yet: the anchor scan is pure Python + numpy today, and the

# where instructions begin, so it over-reports every cross-reference; with one,

# right value. Any use of it must stay behind a guarded import.
